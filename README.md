
# HRMS Costa Rica Enterprise v1

Sistema base de Recursos Humanos y Nómina para Costa Rica.

Incluye módulos:

- Cálculo CCSS
- INS Riesgos del Trabajo
- Impuesto sobre la renta salarial
- Planilla automática
- Liquidaciones laborales
- Reportes de planilla
- Exportación contable
- API REST
- Arquitectura SaaS multiempresa
- Instalación con Docker

Compatible con sistemas basados en Frappe / ERPNext.

Este proyecto es un punto de partida para construir un sistema completo de planilla para Costa Rica.
